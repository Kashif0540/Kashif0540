## ⚡ Features

Terminal style hero with an animated typing effect that cycles through my roles (Full Stack Developer, AI/LLM Engineer, MERN & Laravel Builder, Automation Architect)

* Scroll triggered reveal animations on every section using IntersectionObserver
* Count up stats that animate from 0 when scrolled into view
* Custom dark theme with olive and bone color palette and a signal red accent
* Continuous horizontal tech marquee with inline SVG icons
* Multi column curtain preloader animation on page load
* Fully responsive down to 320px viewport width
* Single HTML file, zero external JS libraries

## 🛠️ Tech Stack
